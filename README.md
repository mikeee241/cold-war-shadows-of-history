# COLD WAR: SHADOWS OF HISTORY

Game edukasi sejarah interaktif berbasis web untuk mempelajari Perang Dingin (1945–1991). Pemain menjelajahi lima bab kronologis, membaca briefing misi, menjawab tantangan pilihan ganda, dan meninjau referensi sejarah.

## Fitur

- Lima bab yang mencakup peristiwa penting Perang Dingin.
- Lima belas tantangan pilihan ganda, tiga tantangan per bab.
- Briefing misi dan debriefing setelah menyelesaikan bab.
- Umpan balik jawaban beserta penjelasan pembelajaran.
- Kartu sumber sejarah untuk membantu memeriksa informasi lebih lanjut.
- Navigasi keyboard, indikator progres, dan tata letak responsif.
- Penjelasan yang membedakan karakter fiktif dalam narasi dari fakta sejarah.

## Teknologi

- React 19 dan TypeScript
- Vite 8
- Tailwind CSS 4
- Lucide React
- Motion

## Persyaratan

- Node.js yang kompatibel dengan Vite 8
- npm

## Menjalankan secara lokal

1. Instal dependensi:

   ```bash
   npm install
   ```

2. Jalankan server pengembangan:

   ```bash
   npm run dev
   ```

3. Buka alamat yang ditampilkan terminal. Secara default, aplikasi tersedia di `http://localhost:3000`.

## Pemeriksaan kualitas

```bash
npm run lint
npm test
npm run build
```

Untuk melihat hasil build produksi secara lokal:

```bash
npm run preview
```

## Materi sejarah

Aplikasi mencakup pembagian dunia pasca-Perang Dunia II, pembentukan aliansi, Krisis Rudal Kuba, perlombaan antariksa, serta berakhirnya Perang Dingin. Kartu referensi pada setiap tantangan menyediakan tautan untuk menelusuri sumber yang relevan.

## Catatan narasi

Karakter pemandu misi merupakan karakter fiktif yang digunakan untuk membingkai aktivitas belajar. Narasi permainan dibedakan dari materi sejarah faktual.
